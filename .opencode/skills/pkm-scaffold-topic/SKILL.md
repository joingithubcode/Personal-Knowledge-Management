---
name: pkm-scaffold-topic
description: Create a new note from the repo template and register it in the category index
---
1. Read pkm/templates/knowledge-template.md and pkm/AGENTS.md. Follow them exactly.
2. Copy the template to pkm/knowledge/<Category>/<topic>.md (lowercase-hyphenated filename) and fill every placeholder.
3. Register the note: add it alphabetically to <Category>/INDEX.md, update the note count in <Category>/SUMMARY.md and in pkm/INDEX.md.
4. Never overwrite an existing file. If the path exists, stop and report it.
