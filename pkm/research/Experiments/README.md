# Experiments

Notes about empirical research experiments and their setups.

## Purpose

Capture durable records of experiments: hypotheses, methods, conditions,
and outcomes, so results remain interpretable and reproducible.

## Scope

- One note per experiment or experimental run.
- Hypotheses, setup, procedure, and results.
- Lessons learned and follow-up questions.

## Folder Contents

- One atomic Markdown note per experiment.
- Each note registered in the repository INDEX.md.

## When to use

- When an experiment is planned or run.
- When an experimental result needs a stable record.
- When a setup must be reproducible later.
