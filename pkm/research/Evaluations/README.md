# Evaluations

Notes assessing approaches, models, or systems on defined criteria.

## Purpose

Capture durable assessments that judge how well something works, with the
evidence and criteria the judgment rests on.

## Scope

- One note per evaluated approach or system.
- Criteria, evidence, and the resulting judgment.
- Limits and conditions of each assessment.

## Folder Contents

- One atomic Markdown note per evaluation.
- Each note registered in the repository INDEX.md.

## When to use

- When an approach needs a recorded assessment.
- When a judgment must survive its context.
- When evidence for or against an approach is gathered.
