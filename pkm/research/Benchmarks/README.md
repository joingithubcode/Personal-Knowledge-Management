# Benchmarks

Notes about evaluation datasets, tasks, and scoring standards.

## Purpose

Capture durable understanding of benchmarks: what they measure, how they
score, and how results across them should be read.

## Scope

- One note per benchmark or benchmark family.
- Task definition, data, metrics, and known caveats.
- How results are compared across studies.

## Folder Contents

- One atomic Markdown note per benchmark.
- Each note registered in the repository INDEX.md.

## When to use

- When a benchmark is used or studied.
- When results need a shared, stable frame of reference.
- When comparing approaches on a standard task.
