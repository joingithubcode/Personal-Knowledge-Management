# Comparisons

Notes that compare approaches, methods, or results side by side.

## Purpose

Capture durable comparisons that clarify differences and trade-offs
between related approaches or findings.

## Scope

- Structured side-by-side comparisons.
- Criteria, trade-offs, and decision-relevant differences.
- Conclusions drawn from comparing sources.

## Folder Contents

- One atomic Markdown note per comparison.
- Each note registered in the repository INDEX.md.

## When to use

- When two or more approaches need systematic comparison.
- When a choice depends on relative trade-offs.
- When differences across findings should be preserved.
