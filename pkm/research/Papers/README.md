# Papers

Notes about individual academic papers and articles.

## Purpose

Capture durable understanding of single papers: their claims, methods,
and findings, so they can be recalled and cited later.

## Scope

- One note per paper read or analyzed.
- Summaries, key contributions, and critical assessments.
- How each paper connects to the wider research.

## Folder Contents

- One atomic Markdown note per paper.
- Each note registered in the repository INDEX.md.

## When to use

- When reading a paper worth remembering.
- When a paper is cited across multiple notes.
- When building a stable record of a research thread.
