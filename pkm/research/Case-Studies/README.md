# Case-Studies

Notes about specific real-world instances and what they teach.

## Purpose

Capture durable accounts of real cases: what happened, what was done, and
the general lessons the case supports.

## Scope

- One note per case or instance studied.
- Facts of the case and the actions taken.
- Lessons that generalize beyond the case.

## Folder Contents

- One atomic Markdown note per case study.
- Each note registered in the repository INDEX.md.

## When to use

- When a real instance is worth preserving.
- When a case yields lessons for future work.
- When concrete evidence grounds a general claim.
