# Surveys

Notes that map a field or topic across its literature.

## Purpose

Capture durable overviews of a field: who did what, what is known, and
what the landscape looks like, without deep critical reading.

## Scope

- One note per surveyed topic or field.
- Structured mapping of work, groups, and themes.
- Orientation for entering an unfamiliar area.

## Folder Contents

- One atomic Markdown note per survey.
- Each note registered in the repository INDEX.md.

## When to use

- When mapping a field before deeper study.
- When a broad overview is worth preserving.
- When entering a topic for the first time.
