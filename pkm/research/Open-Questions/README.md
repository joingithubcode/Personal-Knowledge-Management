# Open-Questions

Notes tracking questions that research has not yet answered.

## Purpose

Capture durable records of open questions: what is unknown, why it
matters, and what is being tried to answer it.

## Scope

- One note per open question or problem.
- The question, its context, and its importance.
- Partial progress and promising directions.

## Folder Contents

- One atomic Markdown note per question.
- Each note registered in the repository INDEX.md.

## When to use

- When a research question is identified.
- When an unknown is worth tracking over time.
- When unanswered questions should not be lost.
