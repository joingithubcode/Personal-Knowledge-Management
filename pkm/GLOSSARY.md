# GLOSSARY.md

Terms used consistently across this repository. Keep definitions short and
self-contained. Add new terms as they enter common use.

## Terms

- **Atomic note**: A note that contains exactly one idea, self-contained
  and linkable on its own.
- **Front matter**: YAML block at the top of a note holding metadata.
- **Wiki link**: A link of the form `[[note-name]]` pointing to another
  note in this repository.
- **Status**: The life-cycle state of a note: draft, active, complete,
  archived.
- **Tag**: A lowercase label attached to a note for grouping and search.
- **Knowledge note**: A finished, durable unit of understanding in the
  knowledge folder.
- **Research note**: A working note capturing an inquiry and its sources.
- **Project note**: Knowledge tied to a specific personal project.
- **Idea note**: An undeveloped thought captured before refinement.
- **Index entry**: A single line in INDEX.md describing one note.

## Notes

- Prefer plain language over jargon.
- Only define terms that appear in the repository itself.
