# Software

Ideas about software, tools, and technical products.

## Purpose

Capture and organize software ideas early, so promising technical
concepts are not lost before they are explored.

## Scope

- Tool and application ideas.
- Technical product and feature concepts.
- Engineering-driven opportunity thoughts.

## Folder Contents

- One atomic Markdown note per idea.
- Each note registered in the repository INDEX.md.

## When to use

- When a software or tool idea appears.
- When a technical concept deserves a record.
- When a build idea needs a home until scoped.
