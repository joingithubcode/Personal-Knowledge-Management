# Artificial-Intelligence

Ideas about AI concepts, applications, and products.

## Purpose

Capture and organize AI-related ideas early, so insights into AI
applications and methods are not lost.

## Scope

- AI application and product ideas.
- Method and capability concepts.
- AI-driven opportunity thoughts.

## Folder Contents

- One atomic Markdown note per idea.
- Each note registered in the repository INDEX.md.

## When to use

- When an AI idea or application appears.
- When a capability concept deserves a record.
- When an AI thought needs a home until explored.
