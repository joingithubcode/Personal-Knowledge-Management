# Career

Ideas about professional direction and growth.

## Purpose

Capture and organize career ideas early, so professional opportunities
and direction thoughts are not lost.

## Scope

- Career direction and role ideas.
- Professional growth concepts.
- Opportunity and trajectory thoughts.

## Folder Contents

- One atomic Markdown note per idea.
- Each note registered in the repository INDEX.md.

## When to use

- When a career idea appears.
- When a professional concept deserves a record.
- When a direction thought needs a home until considered.
