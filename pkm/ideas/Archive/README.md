# Archive

Ideas kept for the record but no longer considered.

## Purpose

Hold the record of ideas that were considered and set aside, so they stay
findable without staying current.

## Scope

- Notes per archived or abandoned idea.
- The record of what was considered and why it stopped.
- Material kept for reference rather than pursuit.

## Folder Contents

- One atomic Markdown note per archived idea.
- Each note registered in the repository INDEX.md.

## When to use

- When an idea is deliberately set aside.
- When an idea should stay readable but unconsidered.
- When a record of past thinking is worth keeping.
