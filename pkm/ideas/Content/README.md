# Content

Ideas about creating and sharing content.

## Purpose

Capture and organize content creation ideas early, so writing, media, and
sharing concepts are not lost.

## Scope

- Writing and article ideas.
- Media and format concepts.
- Sharing and audience thoughts.

## Folder Contents

- One atomic Markdown note per idea.
- Each note registered in the repository INDEX.md.

## When to use

- When a content or article idea appears.
- When a media concept deserves a record.
- When a sharing thought needs a home until developed.
