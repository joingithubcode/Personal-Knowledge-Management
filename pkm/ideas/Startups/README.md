# Startups

Ideas about founding and building new ventures.

## Purpose

Capture and organize startup ideas early, so founder-level opportunities
are not lost before they are assessed.

## Scope

- Venture and founder ideas.
- Startup direction and niche thoughts.
- Opportunity concepts tied to new ventures.

## Folder Contents

- One atomic Markdown note per idea.
- Each note registered in the repository INDEX.md.

## When to use

- When a startup idea appears.
- When a founder-level concept deserves a record.
- When a venture thought needs a home until evaluated.
