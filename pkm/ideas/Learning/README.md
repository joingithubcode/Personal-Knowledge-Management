# Learning

Ideas about learning, study, and skill development.

## Purpose

Capture and organize learning ideas early, so study goals and skill
concepts are not lost.

## Scope

- Topics and skills to learn.
- Study and practice concepts.
- Learning-path and growth thoughts.

## Folder Contents

- One atomic Markdown note per idea.
- Each note registered in the repository INDEX.md.

## When to use

- When a learning goal appears.
- When a skill concept deserves a record.
- When a study thought needs a home until pursued.
