# Future

Ideas about long-term possibilities and directions.

## Purpose

Capture and organize forward-looking ideas, so long-horizon possibilities
and visions are not lost.

## Scope

- Long-term visions and possibilities.
- Future-oriented concepts and trends.
- Ideas awaiting the right time to act.

## Folder Contents

- One atomic Markdown note per idea.
- Each note registered in the repository INDEX.md.

## When to use

- When a long-horizon idea appears.
- When a future concept deserves a record.
- When an idea is right but not yet timely.
