# Archived

Knowledge for projects kept for the record but no longer active.

## Purpose

Hold the preserved record of projects that are no longer worked on, so
their knowledge remains available without staying current.

## Scope

- Notes for each archived project or topic.
- The record of what existed and what was learned.
- Material kept for reference rather than use.

## Folder Contents

- One atomic Markdown note per archived project topic.
- Each note registered in the repository INDEX.md.

## When to use

- When a project is closed or abandoned.
- When a record should stay readable but not maintained.
- When active and completed knowledge must be retired.
