# Planning

Knowledge for projects being prepared but not yet underway.

## Purpose

Hold the thinking that shapes a project before it starts: goals, options,
scope, and the rationale behind the plan.

## Scope

- Notes for each project being planned.
- Goals, scope, and approach decisions.
- The reasoning that a running project will rely on.

## Folder Contents

- One atomic Markdown note per planning topic.
- Each note registered in the repository INDEX.md.

## When to use

- When a project is being shaped or scoped.
- When a plan must be preserved before execution.
- When an idea becomes a concrete project.
