# Templates

Reusable project document shapes for the projects section.

## Purpose

Provide consistent starting shapes for project documents, so every
project begins with the same structure.

## Scope

- One template per recurring project document type.
- Section skeletons only; no content or examples.
- Shapes that adapt to any kind of project.

## Folder Contents

- One Markdown file per project template.
- Each template registered in the repository INDEX.md.

## When to use

- When starting a new project document.
- When a document type recurs across projects.
- When consistency across projects matters.
