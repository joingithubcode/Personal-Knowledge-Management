# Decisions

Knowledge about project decisions and their rationale.

## Purpose

Preserve the choices a project makes and why, so decisions stay
explainable and do not have to be re-litigated.

## Scope

- Notes per significant project decision.
- The options, the choice, and the rationale.
- The record that grounds future direction.

## Folder Contents

- One atomic Markdown note per decision.
- Each note registered in the repository INDEX.md.

## When to use

- When a significant choice is made.
- When a decision's rationale must be preserved.
- When future work depends on past choices.
