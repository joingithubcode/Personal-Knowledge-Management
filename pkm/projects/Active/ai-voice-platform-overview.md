# ai-voice-platform-overview

## Purpose

Describe the AI Voice SaaS platform project at a glance: its goal, market,
architecture, and current status.

## Context

This project is a production-ready AI Voice SaaS platform with the working
name VoiceAI/RunicVoice. It competes with ElevenLabs and JSF Labs and targets
both Pakistani and international markets.

## Main Notes

- The platform is a production-ready AI Voice SaaS product with the working
  name VoiceAI/RunicVoice.
- It competes with ElevenLabs and JSF Labs.
- It targets Pakistani and international markets.
- The backend is built on Python FastAPI.
- The frontend is built on Next.js 15+ with the App Router.
- The platform uses PostgreSQL, Redis, Celery, JWT/OAuth2, and
  S3-compatible storage.
- It requires separate Admin and User dashboards.
- RBAC is enforced strictly at the API level.
- Current status: active development.
