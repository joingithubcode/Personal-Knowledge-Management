# Active

Knowledge for projects currently being worked on.

## Purpose

Keep working knowledge close to the projects that are running now, so
each project's context, progress, and lessons stay reachable.

## Scope

- Notes for each project that is currently active.
- Current context, decisions, and state worth preserving.
- Working material tied to an in-progress effort.

## Folder Contents

- One atomic Markdown note per active project topic.
- Each note registered in the repository INDEX.md.

## When to use

- When work on a project is underway.
- When project knowledge must be captured while fresh.
- When a project's context needs a stable home.
