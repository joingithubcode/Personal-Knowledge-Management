# Meetings

Knowledge captured from project meetings and conversations.

## Purpose

Preserve what matters from meetings: outcomes, agreements, and follow-ups
that a project cannot afford to lose.

## Scope

- Notes per meaningful meeting or conversation.
- Key points, decisions, and agreed actions.
- The record of what was said and settled.

## Folder Contents

- One atomic Markdown note per meeting.
- Each note registered in the repository INDEX.md.

## When to use

- When a meeting produces outcomes worth keeping.
- When an agreement or decision must be preserved.
- When a conversation changes a project's direction.
