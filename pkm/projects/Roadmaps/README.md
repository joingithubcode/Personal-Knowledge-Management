# Roadmaps

Knowledge about project direction and future work.

## Purpose

Capture durable views of where a project is headed: goals, phases, and
the order of work, without tracking day-to-day tasks.

## Scope

- Notes per project roadmap or direction.
- Goals, phases, and sequencing of work.
- The reasoning that guides future effort.

## Folder Contents

- One atomic Markdown note per roadmap topic.
- Each note registered in the repository INDEX.md.

## When to use

- When a project's direction should be preserved.
- When phases and priorities need a stable record.
- When future work must stay grounded in intent.
