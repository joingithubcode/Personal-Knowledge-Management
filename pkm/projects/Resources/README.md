# Resources

Reusable material that supports project work.

## Purpose

Collect the reusable assets and references that projects draw on, so
useful material does not have to be recreated per project.

## Scope

- One note or reference per reusable resource.
- Material shared across multiple projects.
- Assets that are stable and worth keeping.

## Folder Contents

- One atomic Markdown note per resource.
- Each note registered in the repository INDEX.md.

## When to use

- When a resource is useful beyond one project.
- When project work repeatedly needs the same material.
- When a reference should be kept for future projects.
