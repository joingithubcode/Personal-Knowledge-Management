# Completed

Knowledge for projects that have finished.

## Purpose

Preserve the durable knowledge of finished projects: what was built, what
was learned, and what stays useful afterward.

## Scope

- Notes for each completed project.
- Outcomes, lessons, and reusable conclusions.
- The project record that remains after work ends.

## Folder Contents

- One atomic Markdown note per completed project topic.
- Each note registered in the repository INDEX.md.

## When to use

- When a project has reached its end.
- When a project's lessons should be preserved.
- When finished work must remain findable.
