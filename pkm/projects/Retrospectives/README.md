# Retrospectives

Knowledge captured from reflecting on finished work.

## Purpose

Preserve what a project taught: what worked, what did not, and what to do
differently, so lessons feed future projects.

## Scope

- Notes per retrospective or lesson review.
- What worked, what did not, and why.
- Actionable lessons for future work.

## Folder Contents

- One atomic Markdown note per retrospective.
- Each note registered in the repository INDEX.md.

## When to use

- When a project or phase ends and is reviewed.
- When lessons should outlive the project.
- When reflecting on how to work better.
