# templates/

Reusable note templates for this personal knowledge repository.

## Purpose

Provide a consistent starting shape for every new note. Templates enforce
the YAML front matter, section order, and conventions defined in
validation.yaml and AGENTS.md, so every note is built the same way.

## Scope

- One template per content folder: knowledge, research, projects, ideas.
- Section skeletons only; no content, no examples, no placeholders.

## Folder Contents

- knowledge-template.md — for the knowledge/ folder.
- research-template.md — for the research/ folder.
- project-template.md — for the projects/ folder.
- idea-template.md — for the ideas/ folder.

## When to use

- When creating any new note in a content folder.
- As the reference shape when editing an existing note.
- As the base for future template refinements.

## What does NOT belong here

- Actual notes or written content.
- Example knowledge or filled-in samples.
- Project documentation or vendor material.
- Any file that is not a template.

## Related folders

- knowledge, research, projects, ideas: the folders these templates serve.
- AGENTS.md (repository root): the rules templates encode.
- validation.yaml: the standards templates must satisfy.
