# time-blocking-basics

## Purpose

Explain time blocking and why reserving time for tasks beats a to-do list.

## Context

A to-do list says what to do but not when, so tasks slide and the day gets
consumed by whatever is loudest. Time blocking assigns each task a specific
slot on the calendar. The calendar becomes the plan, and tasks happen because
they have a place.

## Main Notes

- Time blocking schedules tasks into fixed blocks of time on the calendar.
- Each block holds one task or a small related group, with a clear start and
  end.
- Blocks protect work from drift: a task has a home, and interruptions must
  contend with the schedule.
- Reviewing the calendar each morning and evening keeps the plan realistic.
- Buffer blocks absorb spillover, emails, and the unexpected.
- Estimate durations honestly; overpacking blocks collapses the plan.
- Recurring blocks for routine work make deep and administrative time
  automatic.
- The method works because it converts intention into a committed schedule.
