# Programming

Knowledge about the craft of writing code.

## Purpose

Capture durable understanding of programming languages, paradigms,
idioms, and practices that stays useful across tools and years.

## Scope

- Language concepts, syntax patterns, and idioms.
- Programming paradigms and design of code.
- Debugging, testing, and tooling knowledge.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When you learn something about programming worth keeping.
- When a technique or pattern deserves durable capture.
- When generalizing a lesson beyond a single project.
