# Software-Engineering

Knowledge about the discipline of building and maintaining software.

## Purpose

Capture durable understanding of engineering practice: process, quality,
architecture decisions, and lessons that shape how software is built.

## Scope

- Engineering practices, processes, and methodologies.
- Code quality, testing strategy, and refactoring.
- Architecture, design patterns, and trade-offs.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When a practice or lesson generalizes beyond one project.
- When capturing durable engineering decisions.
- When the insight guides how software is built.
