# Networking

Knowledge about computer networks and communication.

## Purpose

Capture durable understanding of networking concepts, protocols, and
principles that stays useful across technologies.

## Scope

- Network architecture and the OSI model.
- Core protocols and how they interact.
- Network design and troubleshooting principles.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When capturing a durable networking concept or protocol.
- When understanding how systems communicate.
- When designing or troubleshooting networked systems.
