# knowledge/

Permanent, organized knowledge in this personal knowledge repository.

## Purpose

Store durable, well-developed understanding that has lasting value. Notes
here are the refined output of learning: clear, complete, and stable.

## Scope

- Finished concepts, principles, and frameworks.
- Durable references and distilled understanding.
- Material that has moved beyond draft or active research.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.
- One subfolder per category, each with a README.md and AGENTS.md.

## When to use

- When an idea is fully understood and worth keeping long term.
- When research or project work has matured into general knowledge.
- When a note will remain useful for years.

## What does NOT belong here

- In-progress inquiries or unfinished reasoning.
- Raw sources, quotes, or unprocessed material.
- Knowledge tied to a single personal project.
- Half-formed thoughts or transient notes.

## Related folders

- research: active inquiries that mature into knowledge.
- projects: knowledge scoped to one personal project.
- ideas: raw thoughts not yet ready for this folder.
