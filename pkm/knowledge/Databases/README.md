# Databases

Knowledge about storing, querying, and managing data.

## Purpose

Capture durable understanding of database systems, data models, and
querying that stays useful across engines and years.

## Scope

- Relational and non-relational data models.
- Querying, indexing, and transactions.
- Database design and operational principles.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When capturing a durable database concept or principle.
- When generalizing a lesson beyond one specific engine.
- When designing data storage for a system.
