# Algorithms

Knowledge about algorithms and problem-solving methods.

## Purpose

Capture durable understanding of algorithms, their behavior, and when to
use them, independent of any programming language.

## Scope

- Algorithm families and their mechanics.
- Complexity analysis and efficiency.
- Problem-solving techniques and patterns.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When capturing a durable algorithmic concept.
- When reasoning about efficiency and trade-offs.
- When building problem-solving foundations.
