# technical-interview-preparation

## Purpose

Explain how to prepare for software engineering technical interviews.

## Context

Technical interviews test problem-solving under pressure: coding on the spot,
explaining choices, and communicating clearly. Preparation is a skill like any
other. It means practicing the material, the formats, and the communication
habits that interviews reward.

## Main Notes

- Practice coding problems on data structures and algorithms until the core
  patterns are familiar.
- Understand complexity analysis well enough to justify your solution's
  running time.
- Think out loud: interviewers judge how you approach a problem, not just the
  final answer.
- Clarify the problem before coding: inputs, edge cases, and expected
  behavior.
- Plan before you type: sketch the approach, then implement it.
- Test your solution mentally with examples, including edge cases.
- Be ready for the formats: phone screens, live coding, system design, and
  behavioral rounds.
- Rehearse telling stories about your projects for the behavioral parts.
