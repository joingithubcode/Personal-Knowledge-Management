# Career

Knowledge about professional growth and working life.

## Purpose

Capture durable understanding of career development, working practice,
and professional decisions that stays useful over a lifetime.

## Scope

- Career planning and professional skills.
- Working effectively and communicating.
- Decisions about roles, teams, and direction.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When capturing a durable career lesson or principle.
- When generalizing insight beyond one role or company.
- When reflecting on professional direction.
