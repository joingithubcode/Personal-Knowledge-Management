# supervised-vs-unsupervised-learning

## Purpose

Explain the two main machine learning paradigms and how their data and goals
differ.

## Context

Machine learning draws patterns from data, but the data comes in different
shapes. When each example carries a known answer, the task is supervised;
when there are no labels, it is unsupervised. The choice determines which
algorithms apply and what can be concluded.

## Main Notes

- Supervised learning trains on examples that pair input with a known label
  or target.
- Its goal is to map inputs to outputs so the model can predict the label of
  unseen inputs.
- Regression predicts a continuous value (price, temperature);
  classification predicts a category (spam or not).
- Common supervised algorithms include linear models, decision trees,
  random forests, and gradient boosting.
- Unsupervised learning trains on data with no labels and searches for
  hidden structure.
- Clustering groups similar examples; dimensionality reduction compresses
  data while keeping its shape.
- Semisupervised and reinforcement learning sit between or beside these two
  paradigms.
- Supervised needs labeled data (expensive); unsupervised works with raw
  data but results need interpretation.
