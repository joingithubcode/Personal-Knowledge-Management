# Machine-Learning

Knowledge about teaching machines to learn from data.

## Purpose

Capture durable understanding of machine learning concepts, model
families, evaluation, and practice that stays useful over time.

## Scope

- Learning paradigms and core concepts.
- Model families, training, and evaluation.
- Data handling and applied machine learning.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When capturing a durable machine learning concept.
- When generalizing a lesson beyond one dataset or library.
- When building foundations for deeper learning.
