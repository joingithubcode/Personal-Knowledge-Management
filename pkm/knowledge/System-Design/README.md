# System-Design

Knowledge about designing large, reliable software systems.

## Purpose

Capture durable understanding of system architecture, scalability, and
the trade-offs behind design decisions.

## Scope

- Architecture patterns and system building blocks.
- Scalability, reliability, and performance principles.
- Design trade-offs and decision frameworks.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When capturing a durable design concept or pattern.
- When reasoning about how systems scale and fail.
- When making architecture decisions that outlive a project.
