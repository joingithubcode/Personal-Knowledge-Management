# Security

Knowledge about protecting systems and data.

## Purpose

Capture durable understanding of security principles, threats, and
defense that stays useful as technology changes.

## Scope

- Security principles and threat modeling.
- Common vulnerabilities and defenses.
- Identity, access, and data protection.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When capturing a durable security concept or principle.
- When generalizing a lesson beyond one incident or tool.
- When designing systems that resist attack.
