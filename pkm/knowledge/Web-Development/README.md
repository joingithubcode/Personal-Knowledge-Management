# Web-Development

Knowledge about building for the web.

## Purpose

Capture durable understanding of web architecture, standards, and
practice that stays useful as frameworks change.

## Scope

- Web standards and how browsers work.
- Front-end, back-end, and full-stack principles.
- Performance, accessibility, and web security.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When capturing a durable web concept or standard.
- When generalizing a lesson beyond one framework.
- When building understanding of the web platform.
