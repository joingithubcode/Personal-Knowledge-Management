# seo-fundamentals

## Purpose

Explain the core ideas of search engine optimization (SEO) and how sites
earn organic visibility.

## Context

Search engines decide which pages to show for a query by crawling, indexing,
and ranking content. SEO is the practice of making a site understandable to
those systems and valuable to the people who land on it. It is a long-term,
content-driven effort, not a set of tricks.

## Main Notes

- Search engines crawl the web by following links, index what they find, and
  rank pages against queries.
- Crawlers must reach a page to rank it: internal links and a clear site
  structure help discovery.
- Relevance comes from matching page content to the intent behind a query.
- Titles, headings, and meta descriptions should describe the page honestly;
  content should answer the searcher's need.
- Page speed, mobile usability, and a secure connection (HTTPS) are quality
  signals.
- Fast-loading, mobile-friendly, well-linked pages tend to perform better
  across engines.
- Avoid tactics that try to game rankings, such as hidden text or copied
  content; they risk penalties.
- Measuring helps: track which queries bring visitors and improve the pages
  that serve them.
