# Cloud

Knowledge about cloud computing concepts and practice.

## Purpose

Capture durable understanding of cloud platforms, services, and design
patterns that stays useful across providers.

## Scope

- Core cloud concepts and service models.
- Architecture patterns and trade-offs in the cloud.
- Portability and provider-independent principles.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When capturing a durable cloud concept or pattern.
- When generalizing a lesson beyond one provider.
- When designing systems that run on shared infrastructure.
