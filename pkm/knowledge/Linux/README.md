# Linux

Knowledge about the Linux operating system and its ecosystem.

Capture durable understanding of Linux systems, commands, and internals
that stays useful across distributions.

## Scope

- Core concepts of the Linux operating system.
- Shell, tooling, and system administration.
- System internals and troubleshooting principles.

## Folder Contents

- One atomic Markdown note per topic.
- Each note registered in the repository INDEX.md.

## When to use

- When capturing a durable Linux concept or technique.
- When generalizing a lesson beyond one distribution.
- When working deeper into system internals.
